# Крошечные Подземелья

Мини-игра в духе Teeny Titans, но в антураже D&D: собираешь команду из трёх фигурок и дерёшься на арене, а каждый удар решает бросок d20.

## Как запустить

Двойной щелчок по `index.html`. Всё, никаких установок и интернета.

## Как играть

1. На старте выбери **трёх** героев из шести (Воин, Паладин, Чародей, Волшебник, Бард, Плут).
2. В бою активна одна фигурка — остальные на скамейке.

| Действие | Клавиша |
|---|---|
| Атака | клик по врагу |
| Способность 1 / 2 / 3 | Q / E / R |
| Суперудар | Пробел |
| Смена героя | 1 / 2 / 3 (КД 2 с) |

Энергия общая на команду: 100, старт с 65, восстанавливается 5 в секунду. Каждая способность стоит энергию и имеет свой откат — за бой успеваешь не всё, приходится выбирать.

## Кубик

Каждый удар — бросок d20:

```
d20 + модификатор атаки героя  >=  AC врага   →  попадание
```

* выпало **1** — промах всегда;
* выпало **20** (Плут — 19–20) — крит, урон ×2;
* промах — 0 урона, но видно бросок: `7 + 4 = 11 против AC 13`.

Поэтому Воин с `+5` пробивает бронированного врага, а Волшебник с `+2` чаще мажет — зато «Волшебная стрела» летит без броска.

## Что уже есть

* 6 классов, у каждого 3 способности
* гоблины и скелеты, три врага на бой
* нижняя панель с портретами фигурок и полосой энергии — как в Мини-титанах
* подготовка тяжёлых способностей, замах врагов с «!», вспышки ударов и снаряды, баннер супера
* победа/поражение, золото (сохраняется в браузере), статистика попаданий и критов
* звук (тихий, отключается в коде флага `muted`)
